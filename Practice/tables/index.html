HTML Tables

HTML tables are used to organize and display data in rows and columns.

In this practice section, different types of HTML tables and important table attributes are demonstrated.

1. Basic HTML Table

A basic table consists of rows and data cells. 

<table>

<tr>
    <td>HTML</td>
    <td>CSS</td>
    <td>JavaScript</td>
</tr>

<tr>
    <td>Frontend</td>
    <td>Styling</td>
    <td>Programming</td>
</tr>

2. Table Header

The <th> element defines a table header.

Subject Marks Grade
HTML 85 A
CSS 80 A 
<table>

<tr>
    <th>Subject</th>
    <th>Marks</th>
    <th>Grade</th>
</tr>

<tr>
    <td>HTML</td>
    <td>85</td>
    <td>A</td>
</tr>

3. Colspan

The colspan attribute is used to merge two or more columns.

Student Information
Ali BSCS 5th Semester 
<tr>
<th colspan="3">
    Student Information
</th>

4. Rowspan

The rowspan attribute is used to merge two or more rows.

Student Subject Marks
HTML 85 
<th rowspan="2">
Student

Important Table Tags

Tag Purpose
<table> Defines an HTML table
<tr> Defines a table row
<th> Defines a table header cell
<td> Defines a table data cell
<caption> Defines a table caption

Important Table Attributes

Attribute Purpose
colspan Merges multiple columns
rowspan Merges multiple rows
border Defines table border
cellpadding Adds space inside cells
cellspacing Controls space between cells
