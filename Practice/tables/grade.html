Grade Scale

This table demonstrates how marks are mapped to academic grades and grade points using HTML tables.

It uses table rows, table headers, table data cells and colspan.

Academic Grade Scale

Grade Scale
Grade Marks Range Grade Point
A 85 - 100 4.00
A- 80 - 84 3.75
B+ 75 - 79 3.50
B 70 - 74 3.00
C 60 - 69 2.00
F Below 50 0.00

Grade Information

  • A: 85 - 100 marks, 4.00 grade points
  • A-: 80 - 84 marks, 3.75 grade points
  • B+: 75 - 79 marks, 3.50 grade points
  • B: 70 - 74 marks, 3.00 grade points
  • C: 60 - 69 marks, 2.00 grade points
  • F: Below 50 marks, 0.00 grade points

HTML Concepts Used

  • <table> — Defines the table
  • <tr> — Defines a table row
  • <th> — Defines a table heading
  • <td> — Defines table data
  • colspan — Merges multiple columns
  • CSS classes — Used to style different grades
